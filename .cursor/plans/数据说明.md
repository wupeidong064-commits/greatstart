该文档旨在解释所有需计算数据的定义和实际实现

## 一、核心指标定义与实现对照

### 1. 出勤率相关

#### 1.1 班级出勤率
- **定义**: 出勤人数 / 班级人数
- **实际实现**: ✅ 符合 - 出勤人次 / (排课次数 × 班级总人数)
- **代码位置**: `memfireDB.ts` - `getClassAttendanceStatistics()` 第1422-1427行
- **说明**: 实现逻辑正确，考虑了排课次数和班级人数

#### 1.2 学员出勤率
- **定义**: 排课后 出勤次数 / 应出勤次数（班级开课次数）
- **实际实现**: ✅ 符合 - 累计出勤次数 / 累计应出勤次数（所有班级）× 100%
- **代码位置**: `memfireDB.ts` - `getLowAttendanceStudents()` 第1585-1589行
- **说明**: 正确累计了学员在所有班级的出勤记录，包括已调班的记录

#### 1.3 整体出勤率
- **实际实现**: 实际划课数 / 应划课数
- **代码位置**: `memfireDB.ts` - `getStatistics()` 第2467-2470行
- **说明**: 用于课消收入总结页面

### 2. 场地使用率

#### 2.1 定义
- **定义**: 已开班数 / 最大开班数
- **实际实现**: ✅ 符合 - 活跃班级数 / 最大开班数配置
- **代码位置**: `memfireDB.ts` - `getStatistics()` 第2607-2633行
- **说明**: 
  - 从 settings 表读取 key='maxClasses' 的配置
  - 计算公式: `venueUtilizationRate = classCount / maxClasses × 100%`
  - 如果未设置最大开班数，使用率为 0
  - 前端页面可以点击卡片设置最大开班数

### 3. 课单价

- **定义**: 报名金额 / 报名次数
- **实际实现**: ✅ 符合 - 从成单信息表计算：price / totalLessons
- **代码位置**: `memfireDB.ts` - `getStatistics()` 第2543-2558行
- **说明**: 
  - 为每个学员计算课单价（成交金额/购买课时）
  - 最终计算平均课单价：总支付金额 / 总支付课时数

### 4. 课销金额（确认收入）

- **定义**: 课单价 × 出勤次数
- **实际实现**: ✅ 符合 - Σ(每个学员的课单价 × 该学员的出勤次数)
- **代码位置**: `memfireDB.ts` - `getStatistics()` 第2504-2580行
- **说明**: 逐个学员计算，然后汇总

### 5. 满班率

- **定义**: 班级人数 / 班级容量
- **实际实现**: ✅ 符合 - 总在读学员数 / 总班级容量
- **代码位置**: `memfireDB.ts` - `getStatistics()` 第2490-2501行
- **说明**: 
  - 遍历所有活跃班级
  - 累计：totalEnrolled（活跃报名数）和 totalCapacity（容量）
  - 计算：totalEnrolled / totalCapacity × 100%

### 6. 销售转化相关

#### 6.1 到场率
- **定义**: 到场数 / 添加数
- **实际实现**: ⚠️ 不需要实现
- **说明**: 
  - 体验课表中有"到场数"概念（status='converted'）
  - 根据业务需求，此指标暂不实现
  - 在周总结中使用"爽约率"替代：(邀约数 - 到场数) / 邀约数

#### 6.2 成单率
- **定义**: 成单数 / 到场数
- **实际实现**: ✅ 符合 - 成单数 / 到场体验课数
- **代码位置**: 
  - `memfireDB.ts` - `getSalesNewSignupStats()` 第4487-4490行
  - `statisticsController.ts` - 周总结工作建议模块2，第1177-1180行
- **说明**: 
  - 新签板块：从体验课转化的成单数 / 到场的体验课数
  - 周总结：新增报名 / 到场数

#### 6.3 续费率
- **定义**: 续费数 / 应续费数
- **实际实现**: ✅ 符合 - 已续费学员数 / 应续费学员数（5节课以内）
- **代码位置**: 
  - `memfireDB.ts` - `getSalesRenewalStats()` 第4550-4553行
  - `statisticsController.ts` - 周总结续费率，第1131-1136行
- **说明**: 
  - 应续费学员定义：剩余课时 ≤ 5节的学员
  - 续费率 = 本周已续费学员数 / 当月5节课以内学员数

## 二、不同角色的数据区别

### 2.1 机构整体数据
- **对应**: 所有数据总和
- **实现**: 查询所有活跃数据，不过滤 teacherId 或 classId

### 2.2 工作人员（教练/销售）数据
- **对应**: 工作人员个人数据
- **实现**: 
  - 教练数据：过滤 `teacherId = 当前教练ID` 的班级及其相关数据
  - 销售数据：过滤 `salesId = 当前销售ID` 的成单及相关数据

### 2.3 班级数据
- **对应**: 班级数据
- **实现**: 过滤 `classId = 当前班级ID` 的学员、排课、出勤等数据

## 四、数据一致性验证

### ✅ 已验证正确的计算（8项）
1. **班级出勤率** = 出勤人次 / (排课次数 × 班级人数)
2. **学员出勤率** = 累计出勤次数 / 累计应出勤次数
3. **课单价** = 报名金额 / 报名次数
4. **确认收入** = Σ(课单价 × 出勤次数)
5. **满班率** = 班级人数 / 班级容量
6. **场地使用率** = 已开班数 / 最大开班数（从 settings 表获取）
7. **成单率** = 成单数 / 到场数
8. **续费率** = 续费数 / 应续费数（5节课以内）
