## 一、项目概述

**Buzzer** 是一个专为青少年教育培训机构设计的智能课务管理系统，涵盖学员管理、班级管理、出勤统计、销售管理、财务分析等全业务流程。

### 1.1 核心功能

| 模块 | 功能描述 |
|------|----------|
| **课消收入中心** | 课消统计、收入分析、场地使用率、学员使用率 |
| **现金流中心** | 现金流汇总、月度/周度报表 |
| **学员管理** | 学员信息、报名、调班、流失管理 |
| **班级管理** | 班级创建、排课、出勤签到 |
| **营销销售** | 鱼池线索、体验课、成单管理 |
| **工作人员** | 教练员/销售人员管理、绩效统计 |
| **系统设置** | 机构管理、校区管理、用户权限 |

## 三、认证与权限

### 3.1 认证流程

```
用户登录请求
     │
     ▼
┌─────────────────────────────────────┐
│  POST /api/auth/login               │
│  body: { email, password }          │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│  后端验证 (authController.login)    │
│  1. 查询 users 表                    │
│  2. bcrypt 验证密码                  │
│  3. 生成 JWT Token                  │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│  返回响应                            │
│  { token, user: { id, email, role }}│
└─────────────────────────────────────┘
```

## 五、核心业务逻辑

### 5.1 课消收入计算

#### 确认收入 (课消金额)
```
公式: 课消数 × 平均课单价

平均课单价 = Σ(price / totalLessons) / 成单数
```

实现位置: `backend/src/controllers/consumptionController.ts`

#### 出勤率计算
```
班级出勤率 = 出勤人次 / (排课次数 × 班级人数) × 100%
学员出勤率 = 累计出勤次数 / 累计应出勤次数 × 100%
整体出勤率 = 实际划课数 / 应划课数 × 100%
```

#### 场地使用率
```
场地使用率 = 活跃班级数 / 最大开班数 × 100%
```
最大开班数从 `settings` 表读取 (`maxClasses`)

#### 学员使用率
```
学员使用率 = 课消金额 / 学员数
```

### 5.2 现金流计算

#### 基本盘变化
```
基本盘 = 花名册人数 + 新增 + 召回 - 不续费 - 流失

新增: 新报名学员（非续费）
召回: 从流失学员库召回
不续费: 续费状态为 no_renewal
流失: 添加到 lost_students 表
```

#### 成单分类
```
新签成单: courseType !== '续费'
续费成单: courseType === '续费'
```

### 5.3 其他业务规则

| 规则 | 定义 |
|------|------|
| 蜜月期 | 首次报名30天内 |
| 低出勤 | 出勤率 < 60% |
| 连续请假 | 连续缺勤 ≥ 2次（每周1次课） |
| 应续费 | 剩余课时 ≤ 5节 |
| 满班率 | 总在读学员数 / 总班级容量 × 100% |

## 九、常见问题排查

### 9.1 登录问题

**问题**: 登录后立即返回登录页
**原因**: JWT 验证失败或中间件配置错误
**排查**:
1. 检查后端日志: `pm2 logs buzzer-api`
2. 确认 JWT_SECRET 配置正确
3. 确认中间件使用 `authenticate` 而非 `authenticateMemFire`

### 9.2 权限问题

**问题**: 用户显示权限不正确
**原因**: Auth ID 与 users 表 ID 不匹配
**排查**:
```javascript
// 浏览器控制台
JSON.parse(localStorage.getItem('auth-storage'))
// 检查 user.id 是否与数据库一致
```

### 9.3 API 错误

**问题**: API 返回 500 错误
**排查**:
1. 查看后端日志
2. 检查环境变量是否完整
3. 检查数据库连接

## 十、维护与更新

### 10.1 代码更新流程

```bash
# 1. 拉取最新代码
git pull origin main

# 2. 后端更新
cd backend
npm install              # 更新依赖
npm run build            # 重新编译
pm2 restart buzzer-api   # 重启服务

# 3. 前端更新
cd ../frontend
npm install
npm run build
sudo cp -r dist/* /var/www/buzzer/
```

### 10.2 数据库迁移

```bash
cd backend

# 生成迁移文件
npx prisma migrate dev --name migration_name

# 生产环境应用迁移
npx prisma migrate deploy
```

### 10.3 日志管理

```bash
# PM2 日志
pm2 logs buzzer-api
pm2 flush  # 清空日志

# Nginx 日志
tail -f /var/log/nginx/buzzer_access.log
tail -f /var/log/nginx/buzzer_error.log
```
