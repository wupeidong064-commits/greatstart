## 二、服务器准备

### 2.1 服务器配置要求

| 配置项 | 最低配置 | 推荐配置 |
|--------|----------|----------|
| CPU | 2核 | 4核 |
| 内存 | 4GB | 8GB |
| 硬盘 | 40GB SSD | 100GB SSD |
| 带宽 | 3Mbps | 5Mbps+ |
| 操作系统 | Ubuntu 22.04 LTS | Ubuntu 22.04 LTS |

### 2.2 云服务商选择

推荐国内云服务商（按优先级）：
1. **阿里云** - 稳定性最好，备案流程成熟
2. **腾讯云** - 性价比高，控制台友好
3. **华为云** - 企业级服务

### 2.3 服务器初始化

```bash
# 1. 更新系统
sudo apt update && sudo apt upgrade -y

# 2. 安装基础工具
sudo apt install -y curl wget git vim ufw

# 3. 配置防火墙
sudo ufw allow 22      # SSH
sudo ufw allow 80      # HTTP
sudo ufw allow 443     # HTTPS
sudo ufw enable

# 4. 创建部署用户
sudo adduser deploy
sudo usermod -aG sudo deploy
sudo su - deploy

# 5. 安装 Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 6. 验证安装
node --version  # v20.x.x
npm --version   # 10.x.x

# 7. 安装 PM2（进程管理）
sudo npm install -g pm2

# 8. 安装 Nginx
sudo apt install -y nginx
```

## 三、域名与备案

### 3.1 域名购买与解析

1. **购买域名**
   - 推荐平台：阿里云万网、腾讯云 DNSPod
   - 建议使用 `.com` 或 `.cn` 后缀

2. **DNS 解析配置**
   ```
   类型    主机记录    记录值
   A       @          服务器公网IP
   A       www        服务器公网IP
   A       api        服务器公网IP
   ```

### 3.2 ICP 备案

> 国内服务器必须完成 ICP 备案，通常需要 10-20 个工作日

**备案流程**：
1. 登录云服务商备案系统
2. 填写主体信息（企业/个人）
3. 上传证件材料
4. 等待审核
5. 备案成功后获得备案号

### 3.3 SSL 证书

```bash
# 安装 Certbot（Let's Encrypt 客户端）
sudo apt install -y certbot python3-certbot-nginx

# 申请证书（替换 your-domain.com）
sudo certbot --nginx -d your-domain.com -d www.your-domain.com

# 自动续期测试
sudo certbot renew --dry-run
```

## 四、后端部署

### 4.1 项目准备

```bash

# 创建项目目录
```

### 4.2 环境变量配置

```bash
# 创建生产环境配置
cat > /home/deploy/apps/buzzer/backend/.env.production << 'EOF'
# MemFire 配置
MEMFIRE_URL=https://d4r9c60g91htqli3v480.baseapi.memfiredb.com
MEMFIRE_SERVICE_ROLE_KEY=你的_SERVICE_ROLE_KEY

# PostgreSQL 数据库（如果使用直连）
DATABASE_URL=postgresql://用户名:密码@主机:10000/postgres
DATABASE_DIRECT_URL=postgresql://用户名:密码@主机:10000/postgres

# JWT 配置（生产环境请更换为强密码）
JWT_SECRET=your_production_jwt_secret_at_least_32_chars
JWT_EXPIRES_IN=7d

PORT=3000
NODE_ENV=production

# CORS 配置（替换为你的域名）
CORS_ORIGIN=https://your-domain.com,https://www.your-domain.com

# 创建符号链接
ln -sf /home/deploy/apps/buzzer/backend/.env.production /home/deploy/apps/buzzer/backend/.env
```

## 六、Nginx 配置

### 6.1 创建配置文件

```bash
sudo vim /etc/nginx/sites-available/buzzer
```

### 6.2 配置内容

```nginx
# HTTP 重定向到 HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name your-domain.com www.your-domain.com;

    # Let's Encrypt 验证
    location /.well-known/acme-challenge/ {
        root /var/www/certbot;
    }

    # 其他请求重定向到 HTTPS
    location / {
        return 301 https://$server_name$request_uri;
    }
}

# HTTPS 主配置
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name your-domain.com www.your-domain.com;

    # SSL 证书配置
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers off;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 1d;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # Gzip 压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/json application/xml;

    # 前端静态文件
    root /var/www/buzzer;
    index index.html;

    # 前端路由（SPA）
    location / {
        try_files $uri $uri/ /index.html;

        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
            expires 1y;
            add_header Cache-Control "public, immutable";
        }
    }

    # API 反向代理
    location /api {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;

        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 健康检查端点
    location /health {
        proxy_pass http://127.0.0.1:3000/health;
        access_log off;
    }

    # API 文档（可选，生产环境建议关闭）
    # location /api-docs {
    #     proxy_pass http://127.0.0.1:3000/api-docs;
    # }

    # 日志
    access_log /var/log/nginx/buzzer_access.log;
    error_log /var/log/nginx/buzzer_error.log;
}
```

### 6.3 启用配置

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/buzzer /etc/nginx/sites-enabled/

# 删除默认配置
sudo rm /etc/nginx/sites-enabled/default

# 测试配置
sudo nginx -t

# 重载 Nginx
sudo systemctl reload nginx
```

## 八、CI/CD 自动化部署

### 8.1 GitHub Actions 配置

项目已有 `.github/workflows/ci.yml`，添加自动部署：

```yaml
# .github/workflows/deploy.yml
name: Deploy to Production

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
          cache-dependency-path: |
            frontend/package-lock.json
            backend/package-lock.json

      - name: Install frontend dependencies
        working-directory: frontend
        run: npm ci

      - name: Build frontend
        working-directory: frontend
        run: npm run build
        env:
          VITE_MEMFIRE_URL: ${{ secrets.MEMFIRE_URL }}
          VITE_MEMFIRE_ANON_KEY: ${{ secrets.MEMFIRE_ANON_KEY }}

      - name: Install backend dependencies
        working-directory: backend
        run: npm ci

      - name: Build backend
        working-directory: backend
        run: npm run build

      - name: Deploy to server
        uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SSH_PRIVATE_KEY }}
          script: |
            cd /home/deploy/apps/buzzer
            git pull origin main

            # 部署后端
            cd backend
            npm install --production
            npm run build
            pm2 restart buzzer-api

            # 部署前端
            cd ../frontend
            npm install
            npm run build
            sudo cp -r dist/* /var/www/buzzer/
            sudo chown -R www-data:www-data /var/www/buzzer
```

### 8.2 GitHub Secrets 配置

在 GitHub 仓库 Settings → Secrets 中添加：

| Secret 名称 | 说明 |
|-------------|------|
| `SERVER_HOST` | 服务器公网 IP |
| `SERVER_USER` | SSH 用户名 (deploy) |
| `SSH_PRIVATE_KEY` | SSH 私钥 |
| `MEMFIRE_URL` | MemFire API 地址 |
| `MEMFIRE_ANON_KEY` | MemFire 匿名密钥 |
| `MEMFIRE_SERVICE_ROLE_KEY` | MemFire 服务密钥 |
| `JWT_SECRET` | JWT 签名密钥 |

## 十一、安全加固

### 11.1 SSH 安全

```bash
sudo vim /etc/ssh/sshd_config

# 修改配置
Port 22                    # 或改为非标准端口
PermitRootLogin no         # 禁止 root 登录
PasswordAuthentication no  # 禁用密码登录，使用密钥
PubkeyAuthentication yes   # 启用密钥登录
```

### 11.2 防火墙规则

```bash
# 只开放必要端口
```

## 十二、故障排查

### 12.1 常见问题

| 问题 | 排查步骤 |
|------|----------|
| 网站无法访问 | 1. 检查 Nginx 状态 `sudo systemctl status nginx`<br>2. 检查防火墙 `sudo ufw status`<br>3. 检查端口占用 `sudo netstat -tlnp` |
| API 500 错误 | 1. 查看后端日志 `pm2 logs buzzer-api`<br>2. 检查环境变量 `cat .env`<br>3. 检查数据库连接 |
| 前端白屏 | 1. 检查浏览器控制台错误<br>2. 检查 API 地址配置<br>3. 检查 Nginx 配置 |
| 登录失败 | 1. 检查 MemFire Auth 服务状态<br>2. 检查 JWT 配置<br>3. 查看后端错误日志 |

### 12.2 快速恢复

```bash
# 重启所有服务
pm2 restart all
sudo systemctl restart nginx

# 检查服务状态
pm2 status
sudo systemctl status nginx
```
